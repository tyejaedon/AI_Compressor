# Milestone Template Index

Use these templates when a task starts from a roadmap milestone family rather than a single file.

## Template map

| Template | Covers | Primary theme |
|---|---|---|
| `01-m1-a1-v1-real-compression.md` | `M1`, `A1`, `V1` | real compression accounting, actual latent-size measurement |
| `02-m2-a2-v2-second-wave.md` | `M2`, `A2`, `V2` | advanced second-stage modes: quantization-aware training, streaming inference, temporal compression |
| `03-m3-a3-v3-third-wave.md` | `M3`, `A3`, `V3` | capability expansion: learned upscaling, perceptual loss, data robustness/throughput |
| `04-m4-a4-v4-fourth-wave.md` | `M4`, `A4`, `V4` | robustness/configurability/benchmark breadth |
| `05-m5-a5-v5-alignment.md` | `M5`, `A5`, `V5` | reporting, search, pipeline, and docs alignment |

## How to use them

1. Match the task to the roadmap milestone in `documentation/`.
2. Open the corresponding numbered template here.
3. Open `agent_skills/milestone-delivery.md` for the general delivery checklist.
4. Open the modality playbook (`image-modality.md`, `audio-modality.md`, or `video-modality.md`).
5. If flags, metrics, or orchestration are affected, also open `agent_skills/pipeline-reporting.md`.
